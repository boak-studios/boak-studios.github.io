Boak Studios Analytics

Boak Studios Analytics is an internal tool used only by the studio. After a video is published, it reads that video's statistics (views, watch time, audience retention, subscribers gained) from the YouTube Analytics API for our own channels, so we can learn what works and make better videos. It uses read-only access, it is not offered to anyone else, and it never uploads, edits or deletes anything on YouTube.
